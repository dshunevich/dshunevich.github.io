# Сайт с юридическими страницами (GitHub Pages)

Публикуется в публичный репозиторий `dshunevich/dshunevich.github.io` (код приложений остаётся приватным).
Адреса:
- `https://dshunevich.github.io/` — список приложений и поддержка (Support URL в App Store Connect)
- `https://dshunevich.github.io/<app>/privacy` — политика приложения (Privacy Policy URL)

Публикация: `tools/publish-site.sh` (ключ загрузки `~/.ssh/appstore_pages`, хост `github-pages` в `~/.ssh/config`).
